# Demoblaze QA Testing Project

Manual testing of the Demoblaze demo e-commerce site.

## Scope
Signup, Login, Home Page, Cart, Place Order, Contact Us, Logout

## Files
- Test Cases
- Test Scenarios
- Use Cases
- Bug Report

## Key bugs found
- Weak password validation
- Empty cart bypasses order checks
- Contact form accepts invalid input
- Credit card field format issues
- Footer misalignment

## Tools
Excel, manual exploratory testing
